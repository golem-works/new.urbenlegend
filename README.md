\# 新しい都市伝説カード（Urben Legend Card）

このプロジェクトは、Next.js と Tailwind CSS を使用して構築された都市伝説占いカードの Web アプリケーションです。  
ユーザーがボタンを押すことで、複数の妖怪カードの中からランダムで1枚が表示され、簡単なお告げメッセージを受け取ることができます。

![TOP画面](/assets/screenshot-top.png)
![カード一覧](/assets/screenshot-list.png)

---

## 🔮 特徴

- 都市伝説や妖怪をテーマにした占いカードアプリ
- オリジナルデザインのカード UI
- カードごとの詳細ページあり
- メール送信機能付きお問合せフォーム搭載
- Vercel によるデプロイ済み

---

## 🛠 使用技術

- フロントエンド: **Next.js (TypeScript)** / Tailwind CSS
- デプロイ: **Vercel**
- メール送信: **NodeMailer**
- スタイル: 手書き風UIとホラーテイストのデザイン

---

## 🤖 AI活用について

本アプリで使用している妖怪カードの文章やお告げメッセージの一部は、旧バージョンの GPT を用いて生成しました。  
ただし、AIからの出力はそのまま使用せず、世界観と一貫性を持たせるために構成・編集を行い、**人間が監修したコンテンツ**として仕上げています。  
このように、AIはあくまで素材生成の補助として使用し、主体的な制作は人間が担っています。
